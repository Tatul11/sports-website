Critical gaps in qalampir.uz that KRG Web Sports must fix from day one.

🔴 CRITICAL: Citation Quality (4/10)
Articles reference sources by name but never hyperlink to them. Fix: Add mandatory "Manba:" (Source) section at article end with clickable link to press release, official site, or primary report. This is qalampir.uz's biggest HCU vulnerability.
🔴 CRITICAL: Schema.org Structured Data (MISSING)
Zero schema markup found on qalampir.uz. KRG Web Sports must implement: NewsArticle on all articles → SportsEvent on match pages → Person on author + player profiles → SportsOrganization on club pages → FAQPage on entity pages → BreadcrumbList everywhere. Unlocks rich results & Google News eligibility.
🟠 HIGH: Original Content (5/10)
Most articles repackage external wire stories. Fix: Publish 2 deep-analysis pieces per week per sport. Include proprietary angles: Uzbek player stats, local federation data, exclusive quotes. This is the single biggest differentiation from qalampir.uz.
🟠 HIGH: Entity Pages (MISSING)
qalampir.uz has no player, club, or competition entity pages. KRG Web Sports must build: /futbolchi/abdukodir-husanov/ with full bio, stats, career, news feed, FAQ schema. These pages attract evergreen long-tail queries and compound over time.
🟠 HIGH: Topical Authority (6/10 — multi-niche dilution)
qalampir.uz spreads authority across 7+ niches. KRG Web Sports = sports only → instant topical focus advantage. Build sport pillar pages as hubs with all sub-topics internally linked in a hierarchy. Google rewards deep expertise in a defined domain.
🟢 ADVANTAGE: Russian Language Version
qalampir.uz offers Cyrillic Uzbek, Latin Uzbek, and English — but NO Russian. Adding /ru/ captures the large Russian-speaking Uzbek sports audience. This is an untapped channel for KRG Web Sports.
🟢 ADVANTAGE: Live Scores + Statistics Sections
qalampir.uz has no live scores or statistics hub. /natijalar/ and /jadvallar/ create daily return-visit habits and target high-frequency queries like "Champions League natijalar bugun" — queries qalampir.uz cannot satisfy.
